# Little Bunny · 每日生活书

这是 GitHub Pages 静态版的个人每日记录本。

## 已加入
1. 多选心情 emoji
2. 早餐/午餐/晚餐照片 + 文字
3. 起床/睡觉/午休/夜醒次数
4. 可点击身体部位 + 时间 + 不适描述
5. 奇妙发现照片 + 文字
6. 每日花费
7. 进步/勇敢/羞愧/懊恼/后悔/今日所做
8. 体重/体脂
9. 鼓励墙
10. 电影/音乐/书籍/视频笔记及图片/PDF/Word/Excel/CSV附件
11. 明日生活/学习/工作计划
12. 跨日期未完成备忘录 + 到时页面弹窗（页面打开时检查）
13. 运动类型 emoji + 时长 + 照片 + 文字
14. 日期档案、JSON 备份与恢复

## 数据说明
网站没有后端，记录默认保存在当前浏览器的 IndexedDB 中。GitHub Pages 本身不会替你把私人数据上传到服务器，因此：
- 同一设备、同一浏览器可持续保留历史记录。
- 换设备/清理网站数据前，请使用“备份”下载 JSON。
- 在另一台设备打开网站后使用“恢复备份”即可导入。
- 定时提醒属于网页内提醒；页面未打开时不能保证 iPhone 浏览器弹出系统通知。若以后需要真正的跨设备云同步/后台推送，需要接入数据库和登录服务。
